# music2 0.1.0 (alpha)

**In short**
- This is the first download of music2. It is an alpha: an early test version. Things will break, so keep a copy of any song you care about.
- It runs on Macs with Apple silicon (M1 or newer), and on Linux PCs with an x86_64 processor: the `.deb` on Ubuntu 22.04 or newer and Debian 12 or newer, the AppImage on most Linux from 2023 on. It was tried on Ubuntu 24.04 only.
- The Mac app isn't signed by Apple yet. The first time you open it, macOS needs you to click **Open Anyway** once (see "The first time on a Mac" below).

## What music2 is

music2 is a music studio: a DAW (digital audio workstation), the kind of app people make songs in, like GarageBand. It is made for people new to making music.

In music2 a song is a folder, and the folder is a small program. Code says how the song sounds (the instruments, the effects and the mix). Data files say what plays (the notes, the knob moves and the audio). The window shows the song as a timeline, a piano roll, knobs and cables, and a code editor. Every change you make there is saved into the files at once.

There is no AI inside the app. Scripts and AI agents can work on a song from outside, with the `m2` command line, and you see each change they make land in the window.

## Install on a Mac

1. Download `music2-0.1.0-macos-arm64.zip`. Double-click it, if your browser hasn't unpacked it already. You get `music2.app`.
2. Drag `music2.app` into your **Applications** folder.

### The first time on a Mac

macOS checks every app from the internet. This one isn't signed with an Apple developer certificate, so macOS stops it the first time. You allow it once. These are the steps on macOS 15 (Sequoia) and newer:

1. Open music2. macOS says "Apple could not verify music2 is free of malware". Click **Done**. (Don't click Move to Trash.)
2. Open **System Settings**, then **Privacy & Security**.
3. Scroll down to **Security**. It says "music2 was blocked to protect your Mac". Click **Open Anyway**.
4. Type your password (or use Touch ID).
5. Open music2 again. Click **Open Anyway** once more.

On macOS 11 to 14: Control-click music2 in Applications, choose **Open**, then click **Open** in the message. If it still won't open, allow it in **System Settings → Privacy & Security** (on macOS 11 and 12: **System Preferences → Security & Privacy → General**) with **Open Anyway**.

From then on music2 opens like any other app. Signing the app with Apple, so this step goes away, may come in a later release.

If you use the Terminal, this one line does the same as steps 1 to 5: `xattr -dr com.apple.quarantine /Applications/music2.app`

`m2`, the command line, is inside the app: `/Applications/music2.app/Contents/MacOS/m2`.

## Install on Linux

### The .deb (Ubuntu 22.04 or newer, Debian 12 or newer)

```bash
sudo apt install ./music2_0.1.0_amd64.deb
```

apt also installs the system packages music2 needs, if they aren't there yet: `libwebkit2gtk-4.1-0` (the window's web view), `libgtk-3-0`, `libasound2` (sound, through ALSA), `libdbus-1-3`, and glibc 2.35 or newer (`libc6`). It was tried on Ubuntu 24.04 only: on 22.04 and Debian 12 it should run, as those have every package it needs, but no one has opened it there yet.

Then open music2 from your apps, or type `music2` in a terminal. `m2` is installed as `/usr/bin/m2`. To remove music2: `sudo apt remove music2`.

### The AppImage (other Linux)

The AppImage carries most of its libraries. Your system needs glibc 2.38 or newer, ALSA's library (`libasound2`), and FUSE's `fusermount` program, which desktop Ubuntu and Debian have (the `fuse3` package). It doesn't need FUSE 2 (`libfuse2`).

```bash
chmod +x music2-0.1.0-linux-x86_64.AppImage
./music2-0.1.0-linux-x86_64.AppImage
```

Without `fusermount`, add `--appimage-extract-and-run` at the end of the second line.

### m2 for the AppImage

The AppImage can't hand `m2` to your shell. Download `m2-0.1.0-linux-x86_64.tar.gz` too, then:

```bash
tar xzf m2-0.1.0-linux-x86_64.tar.gz
./m2-0.1.0-linux-x86_64/bin/m2 --version
```

Keep its `bin` and `lib` folders together: `m2` finds the standard sounds, the templates and the examples in `lib`. It needs glibc 2.35 or newer and ALSA's library (`libasound2`, or `libasound2t64` on Ubuntu 24.04 and newer), even on a computer that plays no sound.

## Check your download

The `SHA256SUMS` file holds a checksum of every file. Put it in the folder you downloaded to, and run:

- Linux: `sha256sum -c SHA256SUMS --ignore-missing`
- Mac: `shasum -a 256 -c SHA256SUMS --ignore-missing`

Each file you downloaded should say `OK`.

## What works

- Start a song from a template, or open an example.
- Add tracks: 22 built-in sounds, a Sampler, or audio.
- Draw and edit notes, clips and automation (knob moves over time).
- Mix: faders, pans, mute, solo, meters, buses and sends.
- Play a MIDI keyboard or the computer's keys, and record notes or audio.
- Bring in WAV and MIDI files.
- Play CLAP plugins, and open their own windows.
- Export the song, its stems, or the notes as MIDI.
- Edit the song's code, with type checks.
- Work on a song from a script or an AI agent with `m2`. `m2 docs` prints the guide.

The guide says how to do each: <https://breadbowlai.github.io/music2/>

## What is missing

This is an alpha. The full list of what music2 can't do yet is in [What music2 can't do yet](https://github.com/BreadBowlAI/music2/blob/main/docs/gaps.md). The biggest gaps for this release:

- The Mac app isn't signed or notarized by Apple (the one-time step above).
- The licences of the code inside music2 that others wrote are in `THIRD-PARTY-NOTICES.txt`: in `music2.app/Contents/Resources`, in `/usr/share/doc/music2` from the `.deb`, and beside `bin` in m2's `.tar.gz`.
- No Intel Macs, no Windows, no Linux on ARM.
- No automatic updates: download each new release yourself.
- Before 1.0 the song format can still change. A song made with 0.1.0 may need a line changed to open in a later version.
- Plugins are CLAP only: no VST or Audio Units.
- On Linux, only Ubuntu 24.04 is checked by hand.

Open an issue: <https://github.com/BreadBowlAI/music2/issues/new/choose>. Please say:

- which file you installed, and your system (for example "the .deb on Ubuntu 24.04", or "the Mac app on macOS 15, M2"),
- what you did, what you expected, and what happened,
- if you can, the song folder, zipped, or a screenshot.

`m2 --version` prints the version you have.

A security problem? Please don't open a public issue: report it in private, as [SECURITY.md](https://github.com/BreadBowlAI/music2/blob/main/SECURITY.md) says.
